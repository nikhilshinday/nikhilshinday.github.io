Software Factory Gauntlet

Nikhil Shinday · October 22, 2026

People like Dicklesworthstone and Steve Yegge have built incredible software factories. It’s time for professional software engineers to pick up the vibe-coding gauntlet like them and build high-quality agent primitives.

Steve and Jeffrey demonstrated a degree of agent delegation that seemed psychotic a year ago and is now entirely within reach. In culture and software engineering, however, avoiding the proverbial “slop cannon” is now a detriment rather than a benefit. Professional engineers have a role here: build the high-quality primitives that make this kind of delegation reliable.

So the call to action is: ladies and gentlemen, buy your Wispr Flow subscription and a wireless mic, and get to work building tools for agents, inspired by the slop-cannon frontiersmen.
